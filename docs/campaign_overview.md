## 1. 캠페인 개요

| 항목 | 내용 |
|------|------|
| **제목** | 낙양 탈환 작전 (洛陽奪還作戰 / Recapture of Luoyang) |
| **부제** | 중원의 심장을 되찾아라 |
| **시대** | 923년 — 오대십국 초기, 후량(梁) vs 후당(唐) |
| **규모** | 4개 임무 연속 런(Run), 예상 플레이타임 90분 |

**한 줄 요약:** 황제의 의심과 적의 철창 사이에서, 플레이어는 병사를 살릴 것인가 왕명을 따를 것인가를 매 순간 선택하며 중원의 심장 낙양을 향해 진격한다.

**로그라이트 임무 연쇄 구조:**

```
[M01 국경 돌파] → 야전막사 → [M02 보급선 수호] → 야전막사 → [M03 결전 평원] → 야전막사 → [M04 낙양성 대공성전] → 엔딩(5분기)
     8턴/소형          6턴/중형            10턴/대형              4~10턴/대형 (공성책에 따라)
   (공성 튜토리얼)   (기동전+왕의 전령)   (지형·상성 총력전)    (강공/포위/내통 3택1)
```

각 임무의 잔존 병력·사기·보급·신임도가 다음 임무로 그대로 계승된다. 한 번의 선택이 네 번째 성벽 앞에서 돌아온다.

## 2. 서사 구조 — 왜 '장군의 생존과 선택'인가

본 게임은 국가 경영 시뮬레이션이 아니다. 플레이어는 왕이 아니다. **왕명을 받아 전쟁터로 나간 장군**이다.

이 선택에는 명확한 디자인 의도가 있다:

### 2.1 삼각 긴장 구조

```
         군주(왕)
        /  의심·어명·처형위협
       /         \
      /           \
  장군(플레이어) —— 참모(서유선)
   생존·선택·책임   신중·병사를 아끼는 조언
         \
          \         적장(왕언장)
           \       맹렬·돌격·존경받는 적
            \     /
           전장(지형·병과·보급)
```

- **왕 → 장군:** "3일 내로 성을 떨구지 못하면 참형에 처한다." — 시간 압박, 무리한 강공 유혹
- **참모 → 장군:** "병사를 아끼는 것이 곧 승리를 아끼는 것이옵니다." — 신중, 포위, 내통 유혹
- **적장 → 장군:** "숲 뒤에 숨지 말고 나와서 창을 맞서 보아라!" — 도발, 정면 승부 압박
- **장군은 셋 사이에서 매번 선택해야 한다.** 그 선택이 곧 서사다.

### 2.2 선택의 누적

단발성 선택이 아니다. 모든 선택은 `narrative_flag`로 기록되어 후속 임무에 영향을 준다:

| 이전 선택 | 후속 영향 |
|-----------|-----------|
| 1장에서 포로를 선처 | 2장·4장 투항 이벤트 진짜 확률 +30% |
| 2장에서 보급 수레를 지킴 | 3장 시작 보급 +4일, 장기 포위 가능 |
| 3장에서 왕언장 생포 | 4장 내통 성공률 +20%, 무혈 입성 가능 |
| 난민을 도움 | 민심 상승 → 4장 내통 성공률 +10% |
| 병사 손실 15% 이하 유지 | 서유선 '인자한 수호자' 분기 → 정보 정확도 +20% |

### 2.3 톤 & 문체

- **고풍스럽고 긴장감 넘치는 역사 사극 톤** — 한자 병기, 어어(御語)·간언체·무인의 호통 등 역할별 어조 구분
- 모든 대사는 `line_kr` + `line_han` 병기 — 한자 원문으로 사극의 무게를 더함
- 참모의 대사는 반드시 병법·근거를 댄 뒤 결론을 말함 — "병법이 이르기를... 그러하오니..."
- 왕의 대사는 칭찬 뒤에 반드시 단서를 붙임 — "잘 했느니라. 하나, 짐의 명이 어찌 그리 늦게 당도했는고?"

## 3. 역사적 배경과 각색 원칙

### 3.1 실제 역사

- **923년, 후당(後唐) 장종 이존욱(李存勗)이 후량(後梁)을 멸하고 낙양에 입성** — 오대십국사에서 가장 극적인 역전
- **왕언장(王彦章)** — 후량의 실제 맹장. 철창(鐵槍)으로 유명하며 "왕철창"이라 불림. 당군을 여러 차례 격파했으나 923년 중도 전투에서 생포되어 처형됨
- **낙양(洛陽)** — 당대 중원의 심장. 황하와 낙수가 감싸는 천혜의 요새이자 상징적 수도

### 3.2 각색 원칙

| 원칙 | 설명 |
|------|------|
| **큰 줄기는 역사대로, 세부 임무는 창작** | 낙양 탈환이라는 큰 흐름은 실제 역사(923년 후당의 후량 멸망)를 따르나, 4개 임무의 세부 지형·전투는 게임성을 위해 창작 |
| **실존 인물은 존중, 오리지널 인물로 서사 보강** | 왕언장·장종은 실존, 서유선·조언겸·장문달 등은 서사 기능을 위해 창작. 창작 인물도 시대상에 어긋나지 않게 설정 |
| **병과·지형은 게임 시스템에 충실** | 역사적 병종 고증보다 `UnitType` 7종 / `TerrainType` 7종의 게임 밸런스를 우선 |
| **오대십국 특유의 혼란 강조** | 왕조의 정통성이 불안하고, 장군의 충성이 의심받는 난세의 공기를 서사 전반에 배음 |

## 4. 핵심 시스템 — 왕의 신임도, 참모 분기, 로그라이트 계승

### 4.1 왕의 신임도 (King's Trust) — 0~100

보이지 않는(또는 반투명하게 보이는) 핵심 자원. 모든 선택과 전투 결과가 신임도를 흔든다.

| 구간 | 라벨 | 효과 |
|------|------|------|
| 80~100 | 총애 | 매 임무 보급 +5일, 정예 보병 100 추가 |
| 60~79 | 신임 | 정상 보급 |
| 40~59 | 주시 | '간신의 참소' 이벤트 가중치 증가 |
| 20~39 | 의심 | '회군하라' 조서 강제 발동 가능 |
| 0~19 | 진노 | 4장 실패 시 처형 엔딩 확정 |

- **시작값:** 55 (주시)
- **상승:** 주 목표 달성 +12, 보조 목표 +6
- **하락:** 턴 초과 -8, 퇴각 선택 -15, 보급 낭비 -5
- **4장 엔딩 분기의 핵심 결정 요소**

### 4.2 참모 서유선의 성향 분기

플레이어의 누적 플레이 스타일에 따라 서유선의 조언이 분기한다:

```
                    플레이어의 누적 선택
                           │
          ┌────────────────┼────────────────┐
          │                │                │
    손실 15% 이하      혼합 운용       손실 30% 이상
    저손실 선택 누적                  강공·소모 반복
          │                │                │
   인자한 수호자      현실적 책사      엄정한 간언자
   (Benevolent)      (Pragmatic)      (Stern)
          │                │                │
  정보+20% 매복+15%   모든 선택지 제공  강공 사상자-10%
  사기 기본값+5       페널티 없음       왕 신임도 추가 하락 위험
```

- 분기는 고정되지 않고 **매 임무 사이 야전막사에서 재계산** — 플레이어가 스타일을 바꾸면 분기도 이동
- 대사와 조언 내용이 분기에 따라 달라짐 (같은 상황, 다른 대사)

### 4.3 로그라이트 계승 (Run Persistence)

```
임무 N 종료 시 저장되는 런 데이터:
{
  king_trust, army_morale, supply_days, gold, civilian_trust,
  narrative_flags[],           // 모든 선택의 기록
  remaining_troops[{type, count, morale}],  // 병력 그대로 계승
  advisor_branch               // 참모 분기 상태
}
  ↓
임무 N+1 시작 시 그대로 적용
  + 야전막사 선택(휴식/훈련/정찰) 보너스
  + 신임도에 따른 보급/원군 지원
  + 돌발 이벤트 1~2개 추첨
```

- 병력은 **자동 회복되지 않는다** — 잃으면 그대로 다음 임무에 부족한 상태로 진입
- 보급·사기도 마찬가지 — 2장에서 보급을 잃으면 3장·4장에서 장기 포위가 불가능해진다
- 그래서 **매 임무의 '저손실 승리'가 다음 임무의 선택지를 넓힌다**

### 4.4 야전막사 (Inter-Mission Camp)

각 임무 사이에서 플레이어는 세 가지 중 하나를 선택한다:

| 선택 | 효과 | 추천 상황 |
|------|------|-----------|
| **휴식** | 전군 사기 +6, 보급 -1일 | 사기 50 이하일 때 |
| **훈련** | 징집병 사기 +8, 전체 공격력 +1 (다음 임무 한정) | 징집병 비율 높을 때 |
| **정찰** | 다음 임무 매복/지형 정보 사전 공개 | 3장 결전·4장 공성전 전 |

## 5. 임무 연쇄 상세 (M01~M04)

### M01 — 국경 돌파: 철벽관 함락 (공성 튜토리얼)

- **규모:** 15×12 소형 / 8턴 / 병력 610 vs 420
- **핵심 학습:** FORTRESS 방어 보너스 2.0, 공성병(siege)의 필수성, 궁병 고지 보너스
- **맵:** 중앙 FORTRESS 3칸 + SWAMP 해자 + 숲/산지 측면
- **적 지휘관:** 부장 조영(수비 전문, 왕언장 부재)
- **서사 역할:** "문을 여는 임무" — 왕의 기대와 참모의 신중함이 처음 충돌
- **보상 분기:** 저손실 승리 → 2장 보급 보너스 / 고손실 승리 → 2장 사기 페널티

> **디자인 노트:** 튜토리얼이지만 만만하지 않아야 한다. FORTRESS 2.0 보너스를 공성병 없이 뚫으려 하면 처참한 손실을 보게 하여, 병과 특화의 중요성을 몸으로 배우게 한다.

### M02 — 보급선 수호 / 회군 위기 (기동전 + 왕의 전령)

- **규모:** 18×14 중형 / 6턴 / 병력 600+수레3 vs 기병 340
- **핵심 학습:** 기동전, 보급 오브젝트 방어, 왕의 신임도 시스템 첫 경험
- **맵:** 중앙 ROAD 보급로 + 양옆 평야(기병 돌격로) + 숲(매복) + 습지(기병 저지선)
- **적 지휘관:** **왕언장 첫 등장** — 철창 돌격 AI, 보급 수레를 향해 돌진
- **서사 역할:** "뒤를 지키는 임무" — 전쟁은 앞에서만 벌어지지 않는다. 왕의 의심 전령이 전투 한가운데 당도한다.
- **특수 규칙:** 2턴 종료 시 왕의 조서 강제 이벤트(evt_01 또는 evt_04). 보급 수레 생존 수에 따라 3장 보급 결정.

> **디자인 노트:** 이 임무가 캠페인의 시그니처다. 전투 중 왕의 전령이 당도하는 연출로 "장군의 고독"을 체험하게 한다. 보급 수레를 지키는 것과 왕의 명령에 답하는 것 — 두 가지를 동시에 해야 하는 압박이 핵심.

### M03 — 결전 평원: 왕언장과의 정면 대결 (지형·상성 총력전)

- **규모:** 20×15 대형 / 10턴 / 병력 680 vs 880 (적 우세)
- **핵심 학습:** 병과 상성(창>기>궁>창), 지형 매복, 고지 궁병, 쟁탈전
- **맵:** 중앙 평야(주전장) + 북쪽 숲(매복) + 남쪽 습지(기병 저지) + 동쪽 산지(궁병 고지) + 중앙 마을(쟁탈지)
- **적 지휘관:** **왕언장 주력** — 사기 80, 철창 돌격, 창병 없으면 방어 무시 20%
- **서사 역할:** "바람을 꺾는 임무" — 왕언장의 기병을 지형과 상성으로 꺾어야 낙양으로 갈 수 있다.
- **특수 규칙:** FOREST/SWAMP 매복(1턴 대기 시 발동, 선제 타격 + 사기 피해 +50%), 왕언장 생포 가능(포위 조건)

> **디자인 노트:** 캠페인 최대 규모의 야전. 평야에서 정면으로 붙으면 왕언장에게 쓸리지만, 숲에 창병을 숨기고 습지에 궁병을 배치하면 상성 1.40 + 지형 1.30이 중첩되어 1.82배로 역전된다. "지형을 읽는 자가 전장을 지배한다"는 서유선의 대사를 시스템으로 증명하는 임무.

### M04 — 낙양성 대공성전: 세 갈래 길 (최종 분기)

- **규모:** 20×15 대형 / 4~10턴(공성책에 따라) / 병력 600 vs 700(수비 보너스 포함 시 체감 1400)
- **핵심 학습:** 모든 시스템의 총합 — 공성책 선택이 곧 서사 선택
- **맵:** 중앙 낙양성(FORTRESS 6칸 + 궁성 VILLAGE 2칸) + 해자(SWAMP 10칸) + 4개 성문(ROAD) + 외곽 평야/숲/마을
- **적 지휘관:** 부장 조언겸(내통 분기) 또는 왕언장 잔여 부대
- **서사 역할:** "선택의 임무" — 세 공성책은 세 가지 철학이다.

> **디자인 노트:** 4장은 RECON 페이즈에서 플레이어가 직접 공성책을 선택한다. 이 선택 자체가 서사의 클라이맥스이며, 이후 전투의 맵·턴 제한·승리 조건·보상이 모두 달라진다.

## 6. 4장 공성책 3분기 — 강공 vs 포위 vs 내통

| 구분 | 강공(强攻) | 장기 포위(包圍) | 내통(內通) |
|------|-----------|---------------|-----------|
| **철학** | 피로 산다 | 시간으로 산다 | 꾀로 산다 |
| **서유선 대사** | "피가 강을 이루리이다" | "왕께서 기다려주실지..." | "사람을 잘못 보면 무덤이 열리리이다" |
| **턴 제한** | 6턴 | 10턴 | 4턴 |
| **사상자** | 최대 (25%+) | 최소 (10% 이하) | 최소(성공) / 중간(실패 시 매복) |
| **보급 소모** | 보통 | 극심 (-1일/턴) | 적음 |
| **왕의 신임도** | +12 (빠른 승리 선호) | +6 (느려서 낮음) | +10 |
| **위험** | 병력 고갈 | 보급 고갈 + 왕의 재촉 | 위장 투항 시 매복 |
| **성공률** | 병력에 비례 (안정적) | 보급·신임도에 비례 | 누적 선택에 따라 30~95% |
| **추천 상황** | 병력 충분, 보급 부족 | 보급 충분, 신임도 높음 | 민심 높음, 포로 선처 이력 |

### 내통 성공률 상세

```
기본 50%
+ 1장 포로 선처 ............ +15%
+ 3장 왕언장 생포/선처 ..... +20%
+ 민심 70 이상 ............. +10%
+ 서유선 '인자한 수호자' ... +10%
+ 왕언장이 조언겸 설득 ..... +25% (특수)
─────────────────────────
최대 95% / 최소 30%
```

내통은 도박이지만, 지금까지 "올바른" 선택을 쌓아온 플레이어에게는 가장 보상이 큰 길이다. 이것이 로그라이트 서사의 핵심 — **과거의 선택이 미래의 확률을 바꾼다.**

- **말투:** 어어(御語) — "짐(朕)", "~하라, ~느니라, ~지 않으면 참형에 처하리라"
- **디자인 의도:** 단순한 악역이 아니다. 난세에 즉위한 젊은 황제의 불안이 의심으로 표출된 것. 전공을 세우면 파격적으로 포상하는 입체적 군주.
- **게임플레이:** 신임도 시스템의 주체. 매 임무 전후로 전령·조서·포상/진노로 존재감을 드러냄.

### 참모 — 서유선 (徐有先) [오리지널]

- **나이:** 46세, 청포의 문사
- **말투:** 간언체 — "장군, 병법이 이르기를... 그러하오니 ~하옵니다. 살펴 주소서."

## 11. 밸런스 & 난도

### 11.1 난도 스케일링

| 난도 | 적 병력 | 턴 제한 | 신임도 하락 | 이벤트 페널티 | AI |
|------|---------|---------|-------------|---------------|-----|
| 쉬움 | -20% | +2턴 | -30% | 절반 | 기본 |
| **보통** | **기준값** | **기준값** | **기준값** | **기준값** | **기본** |
| 어려움 | +25% | -1턴 | +30% | 추가 페널티 | 매복 탐지 +20% |

### 11.2 밸런스 의도

- **M01은 반드시 승리해야 함** — 튜토리얼이므로 턴 제한이 넉넉하고 적 병력이 적음. 패배해도 재시도 부담이 없도록.
- **M02가 첫 번째 고비** — 왕의 전령 + 기병 습격을 동시에 처리해야 하므로 초보자가 보급을 잃기 쉬움. 그러나 보급을 잃어도 캠페인이 끝나지 않고 3~4장 난도가 올라가는 구조.
- **M03이 최대 난관** — 적 병력이 아군보다 많음(880 vs 680). 지형·상성을 활용하지 않으면 정면 승부가 불가능하도록 설계. "시스템을 이해했는지"를 검증하는 임무.
- **M04는 선택이 난도를 결정** — 어떤 공성책을 고르느냐에 따라 체감 난도가 완전히 달라짐. 지금까지 잘해온 플레이어에게는 내통이 열리고, 보급을 말아먹은 플레이어에게는 포위가 봉쇄됨.

| 캠페인 | 제목(가제) | 배경 | 연결 |
